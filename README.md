# Daritex - Real Estate Mobile Application

A high-performance, cross-platform mobile application tailored for the real estate market, engineered using **React Native** and **Expo**.

## Key Features & Architecture
- **Cross-Platform Delivery:** Optimized core architecture for seamless deployment on Android ecosystems.
- **Advanced CI/CD Pipeline:** Configured via **EAS (Expo Application Services)** utilizing custom Runtime Versions and Channel Management.
- **Over-The-Air (OTA) Updates:** Implemented a robust OTA workflow for instantaneous hot-fixes without manual store re-submissions.
- **Multi-Ecosystem Adaptability:** Ready for deployment on **Huawei AppGallery** (HMS) and flexible for alternative application distribution.

##  Tech Stack
- **Framework:** React Native (Expo SDK)
- **State Management & Architecture:** Modern JavaScript/TypeScript hooks and optimized component life-cycles.
- **DevOps & Builds:** EAS CLI
